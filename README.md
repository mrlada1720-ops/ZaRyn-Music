# ZaRyn Music
Designed & Developed by Agustinus Daniel.

## Struktur
zaryn-music/
  server.js       server Express + proxy stream audio
  2rmdv4.js       scraper (otak: search, song, album, artist, playlist)
  package.json
  public/
    index.html    tampilan ZaRyn Music

## Menjalankan (Node.js 18 ke atas)
npm install
npm start
Lalu buka http://localhost:3000
